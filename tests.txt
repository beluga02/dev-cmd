TEST 1 — справка без параметров

Команда:
python mathtool.py

Ожидаемый результат:
Решение алгебраических уравнений

Уравнение:
  A*x^2 + B*x + C = 0

Способы запуска:
  python mathtool.py
      вывод справки

  python mathtool.py --help
      вывод справки

  python mathtool.py solve
      ввод коэффициентов A, B и C с клавиатуры

  python mathtool.py solve -a 1 -b -3 -c 2
      решение с заданными коэффициентами

Допустимые значения коэффициентов:
  целые числа от -10000 до 10000

Команда:
